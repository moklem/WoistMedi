# Wo ist Medi? 📍

PWA for sharing your location with friends at **medi Meisterschaft 2026** — using minimal mobile data.

## How it works

- Each user taps the festival map to drop a pin at their location
- Only x/y percentages (~20 bytes) are sent over WebSocket — no GPS data
- Friends see each other's pins update in real time
- Add friends via their 8-character code or QR code

## Setup

### 1. Add the festival map

Download the Lageplan image from `medimeisterschaften.com/medis-2026/lageplan/` and save it as:
```
client/public/lageplan.jpg
```

### 2. Local development

```bash
# Terminal 1 — server
cp server/.env.example server/.env   # edit MONGODB_URI
cd server && npm install && npm run dev

# Terminal 2 — client
cd client && npm install && npm run dev
```

Open http://localhost:5173

### 3. Deploy to Render

1. Push to GitHub
2. Create a **Web Service** on [render.com](https://render.com)
3. Connect the `moklem/woistmedi` repo
4. Render auto-detects `render.yaml` — just add your env vars:
   - `MONGODB_URI` — MongoDB Atlas connection string
   - `JWT_SECRET` — auto-generated by render.yaml
5. Deploy!

## Tech stack

| Layer | Tech |
|---|---|
| Frontend | React 18 + Vite + PWA |
| Realtime | Socket.IO WebSocket |
| Backend | Node.js + Express |
| Database | MongoDB + Mongoose |
| Auth | JWT (30-day tokens) |
| QR codes | qrcode.react |

## Data usage

Each location update = ~20 bytes over WebSocket.  
No GPS, no map tiles — just two numbers.
